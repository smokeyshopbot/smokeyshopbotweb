Channel accessRequired channel, join link and membership checks›

Required channel membership

Add the bot as an administrator in your channel. Telegram leave events clear the membership cache immediately. A short cache keeps repeated actions fast; a fresh check follows when it expires. Use 0 for a live check on every action. Settings apply within 15 seconds.

NotificationsGroup announcements and stock notification rules›

Group announcements

Announcements are sent directly to your public or private group with their emojis and buttons. Add the bot to the group and allow it to send messages. Turn these announcements on or off below. Delivery runs in the background.

Fresh stock notifications

Requested availability alerts

When a product has no available stock, users can tap “Notify me when available”. They receive one alert when stock returns, including after an unpaid hold expires or is cancelled. A normal fresh-stock message also fulfils their request. Alerts use the same stock message and Buy button, with the title “Stock available again!”.

On-chain USDT verification

BEP20 and Polygon both use exact unique-amount matching. Explorer API keys are optional if RPC scanning works, but keeping keys saved improves reliability.

Binance Pay

Use a normal Binance API key with read-only/user data access. Do not enable withdrawals. The bot polls Binance Pay trade history and matches incoming USDT payments by the unique amount shown to the user.

Admin and API domains

First connect both domains to the same WebAdmin service in Railway and verify HTTPS. Open this panel on your chosen admin domain before enabling separation. Enter root URLs here; your private admin path stays separate.

To move the admin domain later: disable separation, connect and open the new admin domain, then enable it with the new URL. API URL changes require resellers to update their configured endpoint. For local testing, leave separation off and set only the API Endpoint URL, e.g. http://127.0.0.1:8080.

Users generate their own key using the Generate API key button. Opening /api does not create a key. Existing keys remain valid; Regenerate API key replaces the old key.

API low-balance alerts

Private Telegram alerts go only to accounts that have actually used your API. Merely having a wallet or generating a key does not qualify. These accounts are monitored after all changes to their shared USDT wallet, including normal bot purchases. Users can opt out under /api. Delivery runs in the background.

Telegram backupsBackup destination, schedule, encryption and status›

Telegram database backups

Encrypted exports go directly to your private Telegram group. Archives use temporary server space and are never stored in MongoDB. Writes briefly pause during export; normal operation resumes before uploading. There is no restore feature in this version.

Daily backups are a sensible starting point on a free MongoDB plan: exports count toward its transfer allowance. Schedule changes apply to the next run; an active upload keeps the settings it started with.
